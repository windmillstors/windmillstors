WINDMILL ORDERS — install as a phone app
1) Upload ALL of these to the GitHub repo that hosts this app:
   index.html, manifest.webmanifest, sw.js, icons/   (Add file -> Upload files -> Commit)
2) Wait 1-2 minutes, open the app link on the phone.
3) Android Chrome: ⋮ -> Install app      iPhone Safari: Share -> Add to Home Screen
